# 输入、筛查和解释边界

## 原始介电列与单位

直接读取文件εr′作为相对介电常数实部ε′、εr″作为损耗ε″；须先核对列名和无量纲单位。εr不自动替代εr′。原值不再投影、不除以其他因子、不再次按面积或厚度归一化。

约定ε*=ε′−iε″、ω=2πf、ε0=8.8541878128×10⁻¹² F/m。

```
ε′ = 文件εr′
ε″ = 文件εr″
σ′(S/m) = 2πf ε0 ε″
σ′(S/cm) = σ′(S/m) / 100
```

逐点检查ε′、ε″与源列相同，独立核对σ′公式和单位。面积、厚度及其他仪器列仅作原始记录。必需列缺失或出现非正/非有限值时报告位置，不默默删点或从Cp–D补算。直接读取这一分析约定并不单独证明仪器导出数值的准确性；科学解释仍取决于测试条件与字段定义。

## 导数谱

ε″der = −(π/2)∂ε′/∂lnω = −(π/2)∂ε′/∂lnf。

若横坐标用 log10f，则要额外除以 ln(10)。不能先对 log ε′求导再称为该导数谱。

- 保留原始 ε′与直接差分导数；默认完整频宽为0.25/0.35/0.50个十进频程，0.35为主。每点取log10f±频宽/2内的实测点，在实际ln(f)坐标上拟合二次多项式，不对原始数据重采样。有效点数至少5，中心两侧各至少2点。
- 要求整个目标窗口处于实测频率范围内，窗口内相邻频率间隔不超过0.15 decade；否则该处导数留空并说明边界/点数不足/频率缺口。每个点记录实际点数、首末频率、实际跨度及状态。实际首末点跨度通常小于目标频宽，这不是重新采样。
- 点数兼容模式默认windows_points=[7,9,13]、primary_window_points=9；可按用户要求统一将主窗口设为13。点数须为互不重复、至少5的奇数，至少两个窗口用于敏感性筛查，主窗口必须在列表中。该模式也保留缺口/端点空缺，不跨大频率缺口拟合。不能把“点数”与“decade”混写。
- 同一比较批次保持已约定的主窗口和筛选规则。发现具体质量问题时，先记录问题及替代方案；不能以目标σTτ更平直作为调整理由。方法变更要建立新的结果版本。
- 只求导过程做局部拟合，不改写原始 ε′、ε″、σ′。边缘无完整窗口处填空，不能伪造外推峰；直接差分仍保留。
- 负值可能反映噪声、起始异常或非单调性，用 symlog 或线性轴显示，不取绝对值、不默默删除。
- 默认正局部峰筛查：相对突出程度≥0.15、半突出程度宽度≥0.15 decade、峰高≥最大正局部峰的0.2。所有其他敏感性窗口在0.16 decade内也有通过筛查的峰，才标为稳定候选。只在连续有效导数片段内寻峰，不跨缺口连接。
- 距测量边界<0.5 decade时警示。保留所有数值极值表和未通过原因；没有稳定峰时如实标注，不强取端点或全局最大值。
- 不同窗口的峰位范围是方法敏感性，**不是置信区间**。多个窗口选择同一个离散频率也不代表零误差。τ_peak=1/(2πf_peak)仅为候选峰对应时间，不能提前改名为 τs。

## 跨温度候选峰跟踪

不同样品各自独立跟踪。P1/P2表示一个温度内按频率排序；轨迹ID表示数值上暂定关联的温度序列，二者不同。

- 温度按升序排列，仅考虑相邻已测温度中的候选峰。不跨越缺峰温度；间隔超过10℃默认不连接。
- 默认每℃最大位移0.12 decade。首次关联使用前一峰位；已有两个观察值时按log10f随温度的最近斜率预测下一峰位。真实位移和相对预测位置的偏差都须在门限内。不强制升温一定向高频。
- 匹配采用互为最佳候选；若同一来源或目标存在两个成本相差≤0.10 decade的备选，标为歧义并断开相关链接，不强行合并/分裂。所有可能链接及拒绝原因写入审计表。
- 断开后新建轨迹；没有峰的温度保留在输入摘要中。轨迹至少3个温度时可称“连续候选序列”，不能称“已确认同一弛豫过程”。短序列、边界警示、是否覆盖所有温度均保存。
- 轨迹图用虚线，误差条表示窗口敏感性，红叉表示测量边缘警示。图不进行Arrhenius/VFT拟合，不确定活化能，不自动指定τs。

上述跟踪门限是探索性设置；峰交叉、快速移动、重叠或信噪比变化都可能导致断轨或错配。审阅匹配表和原谱后再讨论物理归属。

## Ionic Conduction 候选区

从完整频段扫描连续窗口，至少跨1 decade且至少5点。先按相邻实测频率间隔分段，默认screening.max_frequency_gap_decades=0.15；任何候选或灰色对照窗口均不能跨越超过此上限的缺口，两端总跨度不能替代实际连续覆盖。记录缺口边界、跨度、阈值及分段动作到IC_frequency_gap_audit.csv。若各段均不足频宽/点数，报告“连续频段不足”，不把两侧合并。此阈值可依实际采样计划统一调整，不是普适物理判据。

回归 log10σ′–log10f 得 βσ，回归 log10ε″–log10f 得 βε″；必须满足代数关系 βε″=βσ−1。

探索性默认条件：|βσ|≤0.15、σ′最大/最小≤1.5、log10σ′拟合最大绝对残差≤0.05。选通过者中最宽窗口，同宽优先|βσ|小者。报告阈值，并比较斜率限0.10/0.15/0.20和比值限1.25/1.5/2.0。不要为得到想要的结论反复调阈值。

- 橙框=数值候选；灰框=最接近平台但未通过的对照窗口。灰框不能称为 Ionic Conduction 已确认区。
- ε″与σ′两图使用完全相同的频率边界，并画 f⁻¹与常数参考线。它们不是独立的两项证据。
- 若所有区间跨度都不足1 decade或点数不足，标“频段不足”，不框一个假平台。
- 如遇非正/非有限值，不跨越坏点做 log 回归；停止自动筛查并报告具体位置，由用户决定是否另做清理，保留原始数据。
- 接触频率下限时无法判定电极极化边界已分离；接触上限亦提示未完整测量。窗口紧邻内部频率缺口时记录touches_internal_frequency_gap，保留覆盖不完整提示。
- 窗口几何平均 σ′仅是代表交流值，除非物理依据足够，不直接标为 σdc。σ′含弛豫损耗，平台形状本身不能确定载流子类型。

## 文献与证据层级

Wang 等，*Decoupling of Ionic Transport from Segmental Relaxation in Polymer Electrolytes*, PRL 108, 088303 (2012), https://doi.org/10.1103/PhysRevLett.108.088303 。按全文核对概念后再迁移方法；操作阈值来自本工作流程，不是作者给出的标准。

本流程只能提供谱形和候选时间/频段。EIS/BDS 单独不能证明配合离子的完整迁移、自由离子数量相同、离子解离率或扩散机制。σTτs 的恒定性解释还依赖有效载流子浓度和相关运动等假设。扩散/浓度的电极极化模型需要独立识别 EP 峰及确认适用条件，不能把任何导数峰代入。
